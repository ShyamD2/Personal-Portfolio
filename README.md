## 🌟 Interactive Engineering Features

### 1. 🎯 Recruiter "Fast-Track" Role Selector
Interactive specialization selector enabling hiring managers and tech leads to preview tailored dossiers:
- **Kubernetes & SRE**: Custom Go scheduler evaluation hooks, 90.35ns latency, and dynamic 75% waterline bin-packing.
- **Cloud Infrastructure (AWS)**: Multi-region VPC peering fabric, dual Transit Gateway redundancy, and HA subnets.
- **DevOps & CI/CD (IaC)**: 100% codified Terraform modules with remote state locking, automated GitHub Actions, and Trivy scans.
- **DevSecOps & SOAR**: Project AEGIS autonomous incident containment with AWS EventBridge, GuardDuty, and WAFv2.

### 2. 🐒 "Break My Cluster" Chaos Engineering Simulator
Interactive incident injection cockpit simulating real-world distributed systems failures:
- **Spot Instance Eviction**: Sub-second pod drain and bin-packing consolidation under SLA thresholds.
- **400% Traffic Surge**: Real-time autoscaling waterline evaluations.
- **SSH Brute-Force Intrusion**: Autonomous WAF IPSet quarantine containment in 820ms.

### 3. 💰 FinOps Cloud Cost-Reduction Calculator
Real-time AWS EC2 compute cost analysis tool:
- Interactive node count (6–250) and fragmentation (15–55%) sliders.
- Demonstrates up to 50% compute reduction through deterministic bin-packing.

### 4. 🗺️ AWS & Terraform Network Topology Explorer
Multi-tier visualizer for production architecture:
- Ingress/WAF Perimeter &rarr; AWS Transit Gateway Backbone &rarr; EKS Compute &rarr; Aurora Multi-AZ Data Layer.
- Live inspection of CIDR blocks, routing domains, and codified Terraform HCL snippets with one-click copy.

### 5. 📡 Global SRE Telemetry Bar & Procedural Audio Engine
- Sticky 36px bottom status ticker with simulated AWS latency and cluster health.
- Zero-external-asset Web Audio API synthesizers delivering tactile feedback and incident alerts.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run

`ash
# Clone the repository
git clone https://github.com/ShyamD2/Personal-Portfolio.git

# Navigate into the project
cd Personal-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
`
